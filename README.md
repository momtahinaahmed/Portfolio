# Momtahina Ahmed — Portfolio

A personal portfolio website for **Momtahina Ahmed**, a Computer Science and Engineering undergraduate at East West University, digital marketer, and graphic designer based in Dhaka, Bangladesh.

**Live Website:** [momtahinaahmed.vercel.app](https://momtahinaahmed.vercel.app/)

## Overview

This portfolio brings together Momtahina's background, skills, professional experience, education, and certifications in one place. It highlights her work across digital marketing and graphic design while reflecting her ongoing studies in Computer Science and Engineering.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Sections for About, Skills & Services, Experience, Education, Certifications, and Contact
- Mobile-friendly navigation with active section highlighting
- Scroll-triggered reveal effects and animated statistics
- Reduced-motion support for accessibility
- Quick links to email, LinkedIn, GitHub, and certificates
- Profile image fallback and automatically updated footer year

## Built With

- **HTML5** — page structure and content
- **CSS3** — responsive layout, styling, animations, and visual effects
- **JavaScript** — navigation behavior, scroll effects, animated counters, and dynamic year
- **Google Fonts** — Inter and Space Grotesk

## Run Locally

No build tools or package installation are required.

1. Open the project folder in your code editor.
2. Open `index.html` directly in a browser, or use a local development server such as VS Code Live Server.
3. Keep the `assests` directory alongside `index.html` so the styles, scripts, and images load correctly.

An internet connection is needed to load the Google Fonts used by the site.
